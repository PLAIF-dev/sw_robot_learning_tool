# 시연 시나리오 — Robot Learning Tool Prototype

## 준비

```bash
docker compose up --build
# 브라우저: http://localhost:5173
```

---

## 시나리오 1: 신규 학습 세션 생성 및 학습 실행

1. **로그인** — 비밀번호 `1111` 입력
2. **대시보드** 확인 — 기존 세션 요약, 장치 상태 확인
3. **세션** → "신규 학습 세션 생성" 클릭
   - 세션명, 작업 설명 입력 후 생성
   - 생성된 세션을 "현재 세션으로 선택"
4. **학습 실행** 진입
   - **기본 환경 설정**: 로봇/카메라/그리퍼 설정 확인, "다음 단계"
   - **Classifier 학습**: 수집 모드 전환, 성공/실패 라벨 선택, 데이터 수집
   - **데모 수집**: "데모 시작" → 키보드로 TCP 조작 → "성공 입력" → "데모 종료"
   - **본 학습**: "학습 시작" → 에피소드 진행 → 성공/실패 입력 → "체크포인트 저장"
   - **평가/완료**: 단계별 완료 여부 확인, 다음 추천 액션 확인

---

## 시나리오 2: TCP 수동 조작 (키보드)

1. 학습 실행 화면 진입
2. 우측 패널에서 제어 대상 선택 (왼팔 / 오른팔 / 양팔)
3. 조작 모드 선택 (이동 / 회전)
4. 키보드 조작:
   - 왼팔: W/S(앞뒤), A/D(좌우), Q/E(상하)
   - 오른팔: ↑↓←→(앞뒤좌우), PgUp/PgDn(상하)
5. TCP pose, joint state, IK 결과 실시간 확인
6. "기록 시작" → 조작 → "기록 종료"

---

## 시나리오 3: 기록 검토 및 재생

1. **기록 검토** → "수동 조작 기록" 탭
2. 저장된 motion record 선택
3. 재생 패널에서 타임라인 scrub
4. 각 프레임의 pose/joint 상태 확인

---

## 시나리오 4: 체크포인트 관리

1. **모델/체크포인트** 진입
2. 저장된 체크포인트 목록 확인 (성공률, 평균 시간, 생성 시각)
3. 체크포인트를 추가 학습 시작점으로 선택
4. **세션** → "추가 학습 세션 생성" → 체크포인트 연결

---

## Mock 데이터 초기 상태

- 카메라: left/right/head 연결됨 (Mock)
- 로봇: 양팔 연결됨 (Mock)
