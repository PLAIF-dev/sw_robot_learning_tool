# 메뉴 구조 — Robot Learning Tool

## 라우팅

```
/login                  로그인 (비보호)
/app/dashboard          대시보드
/app/sessions           세션 관리
/app/training           학습 실행 (단계형 워크플로우)
/app/review             기록 검토
/app/checkpoints        모델/체크포인트
/app/system             시스템
```

│          │                              │                   │
