# Product Overview — Robot Learning Tool Prototype

## 제품 개요

양팔 로봇 학습 운영 툴의 웹 기반 프로토타입입니다.  
실제 학습 알고리즘 구현이 목표가 아니라, **학습 세션 운영 UX와 전체 워크플로우를 빠르게 검증**하는 것이 목적입니다.

## 대상 사용자

- 로봇 학습 실험을 운영하는 연구자/엔지니어
- 팀 리뷰 및 시연을 위한 내부 사용자

## 핵심 가치

1. **세션 중심 운영** — 학습 세션을 단위로 전체 워크플로우를 관리
2. **단계형 워크플로우** — 환경 설정 → Classifier → 데모 → 본 학습 → 평가
3. **상시 상태 패널** — 로봇/카메라/그리퍼 상태와 TCP 조작이 항상 보임
4. **Mock 기반 시연** — 실제 장비 없이 팀 리뷰 가능

## 현재 구현 범위 (Mock 프로토타입)

- Mock 디바이스 서비스 (실제 장비 연동 없음)
- Mock IK 솔버 (단순 수학 계산)
- Mock 카메라 프레임 (정적 이미지 또는 색상 블록)
- 인메모리 데이터 저장 (재시작 시 초기화)
- 단순 비밀번호 인증 (JWT 없음)

## 향후 실제 구현 시 교체 포인트

- `IDeviceService` → 실제 로봇 SDK
- `IIkService` → 실제 IK 라이브러리
- `ICameraService` → 실제 카메라 스트림
- `ITrainingService` → 실제 RL/IL 학습기
- In-memory store → Database
